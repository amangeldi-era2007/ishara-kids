# Ishara Kids

Рабочий демонстрационный MVP для детей 6–12 лет с интерфейсом на казахском и русском языках. **Никакие настоящие жесты в демо не преподаются:** текущие упражнения посвящены обычным предметам, цветам и формам. Терминология и учебные материалы для жестового языка, используемого в Казахстане (в том числе KRSL, если применимо), должны быть согласованы со специалистами.

## Запуск

Нужен Node.js 20.9+; в Windows PowerShell используйте `npm.cmd`.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:3000. Для проверки: `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run test:e2e`. Для запуска e2e на новом компьютере предварительно установите Chromium: `node node_modules/@playwright/test/cli.js install chromium`.

Публичная версия после публикации через GitHub Pages: https://musulman2607-ship-it.github.io/ishara-kids/. Workflow `.github/workflows/pages.yml` создаёт статический экспорт из ветки `main`; при публикации устанавливается `GITHUB_PAGES=true`, чтобы Next.js учёл подкаталог `/ishara-kids`. Обновления в `main` автоматически публикуются повторно. Хранение прогресса остаётся только в браузере конкретного посетителя.

## Данные и проверка

- Учебные темы и Zod-схема находятся в `src/lib/content.ts`; хранение локального прогресса и правила начисления — в `src/lib/progress.ts`. `ProgressRepository` можно заменить адаптером сервера без изменения схемы интерфейса.
- Перед публикацией реального жеста получите проверку преподавателя/носителя соответствующего жестового языка, источник, право использования и видео с субтитрами и текстовой альтернативой. Схема отклоняет статус `verified` без видео, субтитров, источника и лицензии. Проверку реального содержания делает человек, а не Zod.
- Видео и знаки без подтверждения не отображаются как реальные учебные демонстрации. Сейчас в словаре только карточки-заготовки; реальной базы жестов нет.
- Прогресс и псевдоним хранятся в localStorage браузера. Аккаунтов, камер, аудио, аналитики, распознавания жестов и серверной синхронизации нет. Очистка данных браузера удаляет прогресс; для восстановления нет резервной копии.

## Структура

`src/app` — страницы App Router; `src/components` — оболочка и интерактивный урок; `src/lib` — данные и прогресс; `tests` — браузерный сценарий. `PLAN.md` содержит архитектурный план. Playwright MCP и навыки OpenCode настроены локально в `.opencode` и `opencode.json`.
