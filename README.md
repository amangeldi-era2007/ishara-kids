# Ishara Kids 2.0

Двуязычный атлас для детей 6–12 лет. В заданиях дети работают с понятиями, цветами и формами. Словарь отдельно показывает справочные материалы по казахскому дактилю, а тренажёр отслеживает руки без автоматической оценки букв.

## Запуск

Используйте Node.js 22+. На Windows запускайте команды через `npm.cmd`.

```powershell
npm.cmd ci
npm.cmd run setup:hand-camera
npm.cmd run dev -- --port 3000
```

Откройте http://localhost:3000. Для проверки: `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run test:e2e`. Для запуска e2e на новом компьютере предварительно установите Chromium: `node node_modules/@playwright/test/cli.js install chromium`.

Первый запуск подготовки модели требует сети: скрипт кладёт версию 1 Hand Landmarker в `public/ai`, проверяет SHA‑256 и копирует WASM из закреплённого npm-пакета версии 0.10.35. Повторный запуск использует локальную копию. Проверьте `/practice/diagnostics/` с камерой на компьютере выступления. Доступ к веб-камере работает на `localhost` и HTTPS; открытие по `http://192.168…` на телефоне обычно не даёт доступ.

После `npm.cmd run build` папку `out` можно раздавать любым локальным статическим HTTP-сервером. `next start` не применяется к статическому экспорту.

Проверка камеры в Playwright подаёт локальный видеопоток из тестовой картинки, а не физическую веб-камеру. Для дополнительной проверки двух рук сохраните [тестовое фото MediaPipe](https://storage.googleapis.com/mediapipe-assets/woman_hands.jpg) вне проекта, укажите его путь в `PLAYWRIGHT_TWO_HANDS_FIXTURE` и запустите `npm.cmd run test:e2e`.

Публичный сайт: https://amangeldi-era2007.github.io/ishara-kids/. Workflow `.github/workflows/pages.yml` публикует ветку `main`. При сборке `GITHUB_PAGES=true` включает префикс `/ishara-kids`.

## Данные и проверка

В атласе 8 уроков и 10 тематических категорий. В алфавите (`/dictionary/?category=alphabet`) — 42 карточки: 40 увеличенных снимков из рисунка 1 [статьи о QazSL](https://doi.org/10.3390/technologies14110744) (CC BY 4.0), 41 ссылка на видео из плейлиста [«Әліппе» канала surdo server](https://www.youtube.com/playlist?list=PLMNYxpfNIsWzMjY7uMjZhbrhX5ll6_ss0). Для Ъ и Ь есть видео без снимков; для Ү — снимок и описание из [таблицы Центра](https://special-edu.kz/news/575/single/1671). Фото остаются справочными материалами до педагогической проверки, а видео открываются на YouTube. Атрибуция и оригинал изображения — в [qazsl-attribution.txt](public/content/images/qazsl-attribution.txt).

Импорт учебных материалов описан в [инструкции редактора](docs/content-import.md). Файл импорта: `src/data/reviewed-entries.json`.

- Карточки и проверка метаданных находятся в `src/data/atlas.ts`, упражнения — в `src/lib/content.ts`. Хранение прогресса и правила начисления — в `src/lib/progress.ts`.
- Перед публикацией реального жеста получите проверку преподавателя/носителя соответствующего жестового языка, источник, право использования и видео с субтитрами и текстовой альтернативой. Схема отклоняет статус `verified` без видео, субтитров, источника и лицензии. Проверку реального содержания делает человек, а не Zod.
- Камера необязательна и включается по кнопке в тренажёре. Устройство получает только видеопоток; изображения и ключевые точки не выгружаются и не сохраняются. Прогресс и псевдоним остаются в localStorage. Нет аккаунтов, аналитики и серверной синхронизации.
- **Автоматически распознаваемые буквы: нет.** Локальная модель обнаруживает руки и их точки. Сравнитель статических поз подключён, но набор `src/data/practice-templates.json` не содержит откалиброванных классов. Архив QazSL не раскрывает идентификаторы исполнителей и независимое тестовое разбиение; случайное разбиение не даёт надёжной проверки переноса на новых людей. Урокам не нужны AI-оценки.
- Динамические жесты, выражения лица и предложения не проверяются. Сценарий показа: [PRESENTATION.md](PRESENTATION.md).

## Структура

`src/app` — страницы App Router; `src/components` — оболочка и интерактивный урок; `src/lib` — данные и прогресс; `tests` — браузерный сценарий. `PLAN.md` содержит архитектурный план. Playwright MCP и навыки OpenCode настроены локально в `.opencode` и `opencode.json`.
